# ⚡ dsh-fischl — 原神菲谢尔主题 + Live2D 看板娘

为 **DeepSeek Harness Web** 打造的一键安装外观插件：深空星空主题 + 内置菲谢尔 Live2D 看板娘，点击互动、音素口型、读书待机、表情绑定台词、可视化拖拽位置编辑——**安装即用，无需任何额外配置**。

> 由 [Ghost-Aw](https://github.com/Ghost-Aw) 制作并公开发布。内置菲谢尔 Live2D 模型为作者原创制作，已随插件免费分发。

---

## ✨ 功能特性

- 🎆 **菲谢尔主题外观**：星空银河背景、金色描边、紫色调 token 主题，一键启用（设置 → 通用设置 → 菲谢尔主题）
- 🎀 **内置 Live2D 看板娘**：菲谢尔模型随插件分发（约 60MB），含 **20 种表情**（挤眼、星星眼、可爱、黑脸晕、中二病……）
- 🖱️ **点击互动**：点头部/身体触发不同台词与表情，可给每句台词**绑定固定表情**
- 💬 **音素口型**：台词自动生成口型动画
- 🥚 **连击彩蛋**：快速点击 3 次触发彩蛋台词 + 表情
- 📖 **读书待机**：闲置 28 秒后模型自动进入待机动作循环，点击/打字可唤醒（唤醒台词可开关）
- 🎭 **表情系统**：环境随机表情、点击表情/气泡概率可调
- 🎯 **可视化位置编辑**：直接在模型上拖拽调整空闲位/打字位/头部跟随基准（所见即所得，替代滑块）
- 🧩 **多模型支持**：可浏览选择任意外部文件夹的 Live2D 模型（适配 VTube Studio 表情）
- ⚙️ **DEEP LIVE2D 设置页签**：主题/模型/互动全部可视化配置，支持预设保存与恢复默认

## 📦 安装

### 方式一：GitHub 安装（推荐，安装即用）

```bash
dsh plugin --profile web add github:Ghost-Aw/dsh-fischl
```

> 若 pnpm 提示 git 依赖的 `prepare` 构建被阻止，按提示把对应的 allowBuilds 条目加入
> `$DSH_HOME/profiles/web/pnpm-workspace.yaml` 后重跑一次即可。

### 方式二：npm 安装

```bash
dsh plugin --profile web add dsh-fischl
```

### 方式三：手动安装（无 pnpm 环境）

1. 下载本仓库源码，将 `dsh-fischl` 目录复制到 `$DSH_HOME/profiles/web/node_modules/dsh-fischl`；
2. 在 `$DSH_HOME/profiles/web/package.json` 的 `dsh.profile.bundles` 中加入 `"dsh-fischl"`。

### 启用

安装后**重启 DSH 进程**（完全退出再启动），浏览器刷新页面：

- 主题自动生效（`keepTheme` 默认开启，重启后仍保持）；
- 设置 → 通用设置 → 「⚡ 菲谢尔主题」可随时启用/关闭；
- 右下角菲谢尔看板娘随主题出现。

## 🎮 使用

| 操作 | 效果 |
|---|---|
| 点击模型头部 | 触发头部互动台词（绑定的固定表情） |
| 点击模型身体 | 触发身体互动台词/随机表情 |
| 快速点击 3 次 | 彩蛋：眩晕台词 + 黑脸晕表情 |
| 在输入框打字 | 模型移到打字位（Q 弹弹簧过渡） |
| 闲置 28 秒 | 进入待机动作循环 |
| 输入文字或点击模型 | 唤醒（可自定义唤醒台词与表情） |

### 设置入口

**设置 → DEEP LIVE2D**：

- **主题**：预设/自定义配色、星空开关、背景图片（支持拖拽裁切）
- **Live2D 模型**：模型文件夹下拉/浏览外部文件夹、表情勾选、待机动作选择、位置编辑（拖拽手柄）、缩放与跟随幅度
- **互动**：台词表格（每行可绑定表情、增删行）、连击彩蛋、唤醒台词开关、表情/气泡概率、气泡位置

### 更换模型

1. 点击「浏览…」选择任意包含 `model3.json` 的 Live2D 模型文件夹（工作区内外均可）；
2. 表情/动作列表自动检测（兼容 `exp|expressions`、`motion|motions|animations` 目录结构及 model3.json 引用）；
3. 首次使用新模型自动适配缩放与动作，且**每个模型的参数会自动记忆**，切换回来原样恢复。

## 🗑️ 卸载

```bash
dsh plugin --profile web remove dsh-fischl
```

或手动从 `$DSH_HOME/profiles/web/package.json` 的 `dsh.profile.bundles` 移除 `"dsh-fischl"`，重启 DSH 后删除 `node_modules/dsh-fischl` 目录。

## ❓ 常见问题

- **看板娘不显示？** 确认主题已启用（通用设置 → 菲谢尔主题）；模型从插件内置目录加载，无需联网（渲染库也已内置）。
- **模型显示异常/多手臂？** 内置模型已针对 VTS 双臂参数做适配；外部模型若有类似问题可在模型页检查参数。
- **想要其他模型？** 使用「浏览…」选择任意 Live2D 模型文件夹即可，VTube Studio 模型也可用。
- **渲染库从哪来？** pixi.js、pixi-live2d-display 已内置在插件包内；**Live2D Cubism Core 从官网 CDN 加载**（首次使用需联网，加载后由浏览器缓存，之后基本离线）。
